# Калькулятор КБЖУ по рецепту

[English version](README.md)

Открытый навык для Codex, который рассчитывает калории, белки, жиры и
углеводы (КБЖУ) рецепта: для всего блюда и на 100 г.

## Возможности

- Принимает текст рецепта, изображения, скриншоты и ссылки на рецепты.
- Считает вклад каждого ингредиента по массе и КБЖУ на 100 г.
- Объединяет несколько переданных рецептов или блюд в один расчёт.
- Использует вес готового блюда для расчёта значений на 100 г.
- Уточняет недостающие данные, а не подставляет значения без согласия.

## Установка

Скопируйте папку навыка в каталог навыков Codex:

```text
.agents/skills/podschet-kbzhu-po-receptu/
```

После установки попросите Codex рассчитать КБЖУ рецепта — навык будет выбран
автоматически для соответствующих запросов.

## Пример

```text
Рассчитай КБЖУ блюда: 500 г куриной грудки (110 ккал, 23 г белков,
1,5 г жиров, 0 г углеводов на 100 г) и 200 г риса (350 ккал, 7 г белков,
0,7 г жиров, 78 г углеводов на 100 г). Готовый вес блюда — 600 г.
```

В ответе будут таблица ингредиентов, итог для всего блюда и КБЖУ на 100 г.

## Правила расчёта

Для каждого показателя:

```text
вклад ингредиента = значение на 100 г × масса ингредиента / 100
итог блюда = сумма вкладов ингредиентов
на 100 г = итог блюда / вес готового блюда × 100
```

Промежуточные значения не округляются; округление выполняется только при
показе результата. Если неизвестно КБЖУ продукта или готовый выход блюда,
навык сначала запросит согласие на допущение или уточнение.
